Note that
\[\begin{align*}
s^2=&M_1^2+M_2^2-p_1p_2\\
t^2=&M_1^2+m_1^2-p_1q_1\\
u^2=&M_1^2+m_2^2-p_1q_2
\end{align*}\]
Using momentum conservation, we know that
\[p_1+p_2=q_1+q_2\]
and by squaring both sides,
\[-M_1^2-M_2^2+2p_1p_2=-m_1^2-m_2^2+2q_1q_2\]
Now, for any combination we want, we can find it by inner producting one of the variables on momentum conservation condition. For example,
\[q_1(p_1+p_2)=-m_1^2+q_1q_2\]
and subtituting for $q_1q_2$ and $q_1p_1$ would give $q_1p_2$.

Explicitly,
\[\begin{align*}
s+t+u=&3M_1^2+M_2^2+m_1^2+m_2^2+2p_1(q_1+q_2-p_2)\\
=&M_1^2+M_2^2+m_1^2+m_2^2+2M_1^2+2p_1(p_1)\\
=&M_1^2+M_2^2+m_1^2+m_2^2
\end{align*}\]
where in the second inequality we have used energy conservation.
